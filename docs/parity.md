# Git Twin — Reference parity inventory (gitk / git gui)

> Total: 353 lignes inventoriees.

## Etat du prototype (2026-10-12)

Audit du 2026-10-12. Les statuts proviennent de l'inspection du code (menus,
raccourcis, actions, handlers) et des tests manuels de l'utilisateur : lancement
et options CLI, lecture seule, dispositions compact et 120x35, F1/F2/F6/F10/F11,
menus et menus contextuels, preferences, historique des messages de statut, vue
Historique (graphe, tags, --all, filtre de chemin, recherche, navigation et
options du diff, menus, visionneuse de fichiers, editeur externe, fleches du
graphe), vue Worktree (indexation, rejet, annuler/refaire, message de commit,
commit, sign-off, amend, stash, branches, fetch, push, prune, remotes, hard reset,
merge local, abort, continue/abort, outils, merge tool, difftool). Non testes
manuellement : resolution de conflits merge/rebase, signature, hooks,
authentification. Le statut `verifie` signifie test automatise ou test manuel
de l'utilisateur.

Repartition (353 lignes) : verifie 254 ; implemente 47 ; adaptation documentee 10 ;
bloque 0 ; specifie 42.

Les statuts `implemente` non verifies ne doivent pas etre lus comme verifies. Voir `limitations.md`.

Les deux dispositions sont implementees dans `src/ui/mod.rs`, avec les menus
et formulaires dans `src/ui/overlays.rs`. `tests/prototype.rs` couvre le rendu,
le redimensionnement, l'indexation par clic sur l'icone, le refus en lecture seule,
le commit simple et le lancement/bascule/sortie en pseudo-terminal.

- Date de releve: 2026-10-07.
- OS: Ubuntu 24.04.5 LTS, x86_64; locale: en_US.UTF-8.
- Git: `git version 2.43.0`.
- Paquets Debian: `git-gui 1:2.43.0-1ubuntu7.3`, `gitk 1:2.43.0-1ubuntu7.3`.
- Sources lues: `/usr/bin/gitk` (Tcl, 12802 lignes), `/usr/lib/git-core/git-gui` (4130 lignes), modules `/usr/share/git-gui/lib/*.tcl` (total sources releve 30026 lignes).
- Versions internes: gitk ne declare pas `appvers`; son About indique copyright 2005-2016 Paul Mackerras et le script lit `git version` a l execution (`gitk:3150-3158`, `gitk:12678`). git-gui declare `set appvers {0.21.0.116.g0730a}` et `git-gui --version` imprime `git-gui version 0.21.0.116.g0730a` (`git-gui:3-12`).
- Configuration Git globale relevee (filtre inoffensif): `core.editor code --wait`; aucun item global `gui.*`, `gitk.*`, `merge.tool` ou `diff.tool` releve.
- Captures: non produites, car `command -v xvfb-run` et `command -v Xvfb` ne retournent rien; `import` et `xwd` existent mais aucune fenetre n a ete ouverte sur le DISPLAY utilisateur.

## Methode

- Section 3 de `design.md` lue avant inventaire: elle impose une matrice de parite par commande, option, menu, dialogue, geste et comportement observable.
- Inventaire derive des sources Tcl installees via lectures ciblees et grep; aucun comportement n est invente depuis la memoire. Les cellules `Emplacement` citent le fichier source et la ligne approximative.
- Aucune experimentation graphique ni modification de depot existant; seuls `docs/parity.md` et `docs/reference-notes.md` sont ecrits.

- `specifie`: comportement documente depuis le code source.
