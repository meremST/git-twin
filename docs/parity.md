# Git Twin — Reference parity inventory (gitk / git gui)

> Total: 353 rows inventoried.

## Prototype state (2026-10-12)

Audit of 2026-10-12. Statuses come from code inspection (menus,
shortcuts, actions, handlers) and from the user's manual tests: launch
and CLI options, read-only mode, compact and 120x35 layouts, F1/F2/F6/F10/F11,
menus and context menus, preferences, status message history, History
view (graph, tags, --all, path filter, search, diff navigation and
options, menus, file viewer, external editor, graph
arrows), Worktree view (staging, discard, undo/redo, commit message,
commit, sign-off, amend, stash, branches, fetch, push, prune, remotes, hard reset,
local merge, abort, continue/abort, tools, merge tool, difftool). Not manually
tested: merge/rebase conflict resolution, signing, hooks,
authentication. The `verified` status means an automated test or a manual test
by the user.

Breakdown (353 rows): verified 254 ; implemented 51 ; documented adaptation 11 ;
blocked 0 ; specified 37.

`implemented` statuses that are unverified must not be read as verified. See `limitations.md`.

Both layouts are implemented in `src/ui/mod.rs`, with menus
and forms in `src/ui/overlays.rs`. `tests/prototype.rs` covers rendering,
resizing, staging by clicking the icon, read-only refusal,
the simple commit and the launch/toggle/exit in a pseudo-terminal.

- Survey date: 2026-10-07.
- OS: Ubuntu 24.04.5 LTS, x86_64; locale: en_US.UTF-8.
- Git: `git version 2.43.0`.
- Debian packages: `git-gui 1:2.43.0-1ubuntu7.3`, `gitk 1:2.43.0-1ubuntu7.3`.
- Sources read: `/usr/bin/gitk` (Tcl, 12802 lines), `/usr/lib/git-core/git-gui` (4130 lines), modules `/usr/share/git-gui/lib/*.tcl` (total sources surveyed 30026 lines).
- Internal versions: gitk does not declare `appvers`; its About shows copyright 2005-2016 Paul Mackerras and the script reads `git version` at runtime (`gitk:3150-3158`, `gitk:12678`). git-gui declares `set appvers {0.21.0.116.g0730a}` and `git-gui --version` prints `git-gui version 0.21.0.116.g0730a` (`git-gui:3-12`).
- Global Git configuration surveyed (harmless filter): `core.editor code --wait`; no global `gui.*`, `gitk.*`, `merge.tool` or `diff.tool` item found.
- Screenshots: not produced, because `command -v xvfb-run` and `command -v Xvfb` return nothing; `import` and `xwd` exist but no window was opened on the user's DISPLAY.

## Method

- Section 3 of `design.md` read before the inventory: it requires a parity matrix by command, option, menu, dialog, gesture and observable behavior.
- Inventory derived from the installed Tcl sources via targeted reads and grep; no behavior is invented from memory. The `Location` cells cite the source file and approximate line.
- No graphical experimentation or modification of an existing repository; only `docs/parity.md` and `docs/reference-notes.md` are written.

## Status legend

- `specified`: behavior documented from the source code.
- `to inventory`, `implemented`, `verified`, `documented adaptation`, `blocked`: statuses reserved by the project; not used except as future need arises.
